Prototype · strategic early warning system

Disney Strategy War Game

Simulates Disney against 12 competitors and 4 startup archetypes over FY27–FY36, thousands of times, then surfaces the themes that keep showing up in the bad futures. Every assumption is a slider for the team to argue with. Illustrative draft assumptions, not a forecast.

PESTEL shock weights

How often each category of shock fires. 3 = draft baseline, 1 = rare, 5 = frequent.

Competitor aggression

How likely each player is to make its threatening move in a given year. 50 = draft baseline.

Startup archetypes

Chance per year that each disruptor arrives. Once it arrives, it stays.

    Starting point: FY26 actuals from Disney's FY26 Q4 8-K: Experiences $11.19B, Entertainment $5.44B, Sports $3.09B segment operating income (total $19.7B).

    How it works: each simulated year, shocks and competitor moves fire with the probabilities set on the left. Each one cuts (or lifts) segment profit for a set number of years. The chosen playbook sets base growth and how exposed each segment is to each kind of threat. All impacts, probabilities and playbook settings are draft assumptions by Jake Schmidt, built to be overwritten with the team's own views and data.

    Not modeled yet: balance sheet, M&A by Disney, 2019 backtest mode. Built as a prototype for discussion.
